# AGENTS.md

## What this repo is

Companion repository for a YouTube channel focused on developer tooling, terminal workflows,local AI, etc. Each episode gets its own directory containing every file shown or referenced in the video: scripts, configs, dotfile snippets.

## Conventions

- Episode dirs are named `kebab-title`.
- No secrets or credentials committed — use placeholders and document the expected path.
- Each episode dir is self-contained; a viewer should be able to clone, read the README, and be up and running.
- Link each episode dir in README.
